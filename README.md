# tcenteros

tcenteros is a **Training Center Operating System** designed for fitness centers,
training institutes, and academies to manage members, trainers, payments,
attendance, schedules, and reports — all in one platform.

## Core Modules
- Member Management
- Trainer Management
- Attendance (Manual / QR)
- Membership & Packages
- Payments (Inward & Outward)
- Slot & Batch Scheduling
- Reports & Analytics
- Multi-branch Support (future)

## Tech Stack (Proposed)
- Frontend: React / Next.js
- Backend: Node.js (NestJS) or FastAPI
- Database: PostgreSQL
- Mobile: Flutter
- Infra: AWS + Docker
